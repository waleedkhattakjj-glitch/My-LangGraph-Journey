# Persistence in LangGraph 

This project demonstrates how **Persistence** works in LangGraph using checkpoints and workflow state management.

##  Workflow

The AI workflow:
1) Generates a joke
2) Explains the joke
3) Saves workflow state using `InMemorySaver`

##  Technologies Used

* Python
* LangGraph
* LangChain
* Groq LLM
* InMemorySaver

##  Concepts Learned

* Persistence in LangGraph
* Short Term Memory
* Human in the Loop
* Fault Tolerance
* Time Travel
* Workflow State History
