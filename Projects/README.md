# Simple Chatbot with LangGraph

This project demonstrates a simple conversational AI chatbot built using LangGraph and Groq LLMs.

##  Features

* Interactive chatbot workflow
* Conversation memory support
* Message state management
* Persistent chat history using InMemorySaver

##  Technologies Used

* Python
* LangGraph
* LangChain
* Groq LLM
* InMemorySaver

##  Concepts Learned

* State Management
* Message Handling
* Persistence & Memory
* AI Conversation Flow
* Workflow Compilation

##  Model Used

* `openai/gpt-oss-120b`
