# Iterative Flow with LangGraph 

This project demonstrates an **Iterative AI Workflow** using LangGraph, where an AI system can generate, evaluate, and optimize LinkedIn posts in a loop until the content is approved.

##  Workflow

1️⃣ Generate LinkedIn Post
2️⃣ Evaluate Post Quality
3️⃣ Optimize Rejected Content
4️⃣ Re-evaluate Until Approved

##  Technologies Used

* Python
* LangGraph
* LangChain
* Groq LLMs
* Pydantic
