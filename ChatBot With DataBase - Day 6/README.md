# Chatbot with Database Memory 

This project demonstrates a LangGraph chatbot with persistent memory using SQLite database checkpointing.

##  Features

* Interactive AI chatbot
* Persistent conversation memory
* SQLite database integration
* Stateful conversation handling
* Chat history management using `thread_id`

##  Technologies Used

* Python
* LangGraph
* LangChain
* SQLite
* Groq LLM

##  Concepts Learned

* Persistent Memory
* Database Checkpointing
* Stateful AI Workflows
* Conversation Management
* Chat History Storage

##  Model Used

* `openai/gpt-oss-120b`
